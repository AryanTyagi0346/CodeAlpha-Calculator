# CodeAlpha Calculator

## Project Description

This is a simple and responsive calculator developed as part of the CodeAlpha Frontend Development Internship. It is built using HTML, CSS, and JavaScript and performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear (C) button
- Responsive design
- Modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
CodeAlpha_Calculator/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Start using the calculator.
